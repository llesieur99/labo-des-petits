# Travail avec GitHub

Référence publique : https://github.com/llesieur99/labo-des-petits.

1. Vérifier git status, puis récupérer les changements avec git fetch et une
   avance rapide lorsque le dossier de travail est propre.
2. Réaliser un lot cohérent et lancer tools/verif.sh.
3. Inspecter le diff et vérifier l’absence de secrets et de données personnelles.
4. Utiliser un nom de contributeur public et une adresse GitHub noreply.
5. Committer et publier les changements validés sur main, sans force-push.
6. Vérifier que les SHA local et distant correspondent.

Ne jamais versionner _local/, .env, clés, profils Apple, keystores, bases de
données personnelles, journaux privés ou coordonnées de validation boutique.
Le dépôt public commence avec un historique nettoyé. Les captures de présentation
et les noms utilisés dans les tests représentent des données de démonstration.
